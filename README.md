🎬 Movie Recommendation System

📌 About the Project

I created this project to build a simple Movie Recommendation System using Python.

The system takes a movie name and recommends similar movies based on genres, keywords, cast, and other movie features.

🎯 Objective

The main objective of this project is to recommend similar movies using a content-based filtering approach.

🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Kaggle Notebook

📂 Dataset

I used the TMDB 5000 Movie Dataset.

The dataset contains information such as:

- Movie title
- Genres
- Keywords
- Cast
- Crew
- Ratings
- Number of votes
- Popularity

🔧 Project Steps

1. Loaded the movie and credits datasets.
2. Merged both datasets using Movie ID.
3. Selected the required columns.
4. Cleaned missing and duplicate data.
5. Combined movie features such as genres, keywords, cast, and director.
6. Used TF-IDF Vectorization to convert text into numerical values.
7. Used Cosine Similarity to find similar movies.
8. Created a recommendation function.
9. Tested the system with different movies.
10. Created a visualization for top-rated movies.

🎬 Recommendation System

The system uses Content-Based Filtering.

For example, when a user enters a movie like Avatar, the system recommends movies with similar features.

📊 Visualization

The project includes a chart showing the Top Rated Movies based on ratings and vote counts.
